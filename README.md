# ОТ-АВГУСТ

Статический тест по охране труда для GitHub Pages. Без сборки, зависимостей и внешних сервисов.

## Возможности

- Общий вход по почте и паролю, без регистрации.
- Имя участника перед прохождением; 20, 50 или все вопросы выбранного раздела. Все параметры и полный список разделов видны сразу, без раскрывающихся меню.
- Секундомер или таймер на 1–600 минут. Истечение таймера завершает тест автоматически.
- Автосохранение незавершённой попытки и восстановление после обновления.
- История в localStorage браузера, разбор ответов, повтор ошибок. Основная статистика и CSV учитывают только полностью пройденные попытки; прерванные попытки не сохраняются, старые неполные записи удаляются из локальной истории.
- Экспорт результата в TXT и истории в CSV.
- Тренировка: немедленная зелёная/красная проверка ответа и номера вопроса. Ответ фиксируется, пропуски нужно заполнить до завершения.
- Экзамен: 20 минут, допускаются 3 ошибки; четвёртая ошибка или истечение времени прерывают попытку.
- Тёмный квадратный интерфейс, верхняя навигация, закреплённые кнопки прохождения. SF на Apple. На маленьких экранах очень длинный текст прокручивается внутри области вопроса, кнопки остаются видны.

## Данные

633 уникальных скриншота из Doc1–Doc6, восемь разделов. Один повтор изображения удалён. Зелёный вариант использован как единственный правильный ответ. Тексты распознаны OCR; исходные нейтральные фрагменты доступны у каждого вопроса для сверки.

После независимой сверки 3147 текстовых полей доступны 625 вопросов. Восемь исключены из новых попыток: исходные скриншоты обрезают продолжение ответа. В Doc3 отсутствует вопрос №10 раздела расследования несчастных случаев. Недостающий текст не придуман. Отчёт: `docs/question-audit.txt`, полный журнал исправлений: `docs/question-corrections.json`. Ключи всех 633 вопросов проверены по зелёному выделению. Это проверка точности переноса документов, а не актуальности нормативных актов.

## Ограничения статического размещения

Общий вход — локальная проверка на клиенте. Он не защищает публичные файлы и ключи ответов от просмотра исходного кода. Почта входа техническая, отправка писем не используется. Пароль не хранится открытым текстом в репозитории.

История не передаётся на сервер и не синхронизируется между устройствами. Очистка данных браузера удаляет её, поэтому результаты можно скачать.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765. Простое открытие index.html через file:// не подходит для загрузки JSON.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Никакой сборки не требуется. `.nojekyll` отключает Jekyll.

## Изменение общего доступа

В `app.js` объект AUTH содержит техническую почту, соль и SHA-256 от строки `salt:password`. Для смены пароля обновите хеш. Не храните открытый пароль в публичном репозитории.

## Проверка логики

`node tests/quiz.cjs` — 27 комбинаций раздела/количества, проверка и фиксация ответов, пропуски, порог экзамена, таймаут, история завершённых попыток.

Оптимизация: индекс вопросов Map; исходные скриншоты загружаются только при открытии исходного текста; иллюстрации знаков отдельными кэшируемыми WebP, без ожидания большого JSON перед показом вопроса.
